# Simple ToDoList

A simple and interactive ToDo List web application built using HTML, CSS, and JavaScript.

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Simple and clean user interface

## Technologies Used

- HTML
- CSS
- JavaScript

## Project Structure

```text
ToDoList/

│── index.js
│── mobileUI.jpeg

│── style.css
│── todo.js
└── todoUI-pc.png
```

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/SwatiManjari/Simple_ToDoList.git
```

2. Open the project folder.

3. Open `index.html` in your browser.
