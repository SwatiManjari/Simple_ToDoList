# Simple To-Do List

A simple and beginner-friendly To-Do List web application built using **HTML, CSS, and JavaScript**.

## Features

* Add new tasks
* Mark tasks as completed
* Simple and clean user interface
* Responsive layout

## Technologies Used

* HTML
* CSS
* JavaScript

```text
Simple_ToDoList/
│

```

## Live Demo

The project is deployed using GitHub Pages.

## About

This project was created to practice the fundamentals of JavaScript and DOM manipulation while building a simple real-world web application.
